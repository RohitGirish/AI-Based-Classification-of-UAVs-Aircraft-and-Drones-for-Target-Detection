# AI-Based Target Detection and Classification of UAVs, Aircraft, and Drones

## Overview
This project presents an AI-powered system for detecting and classifying aerial targets, including UAVs, aircraft, and drones, using ADS-B flight trajectory data. Leveraging a Transformer-based deep learning model, the system analyzes temporal flight patterns to accurately identify different types of aerial vehicles. The solution is designed for defense, surveillance, and airspace monitoring applications.

## Features
- AI-driven aerial target detection and classification.
- Multi-class classification of UAVs, aircraft, and drones.
- Flight trajectory analysis using ADS-B data.
- Transformer-based deep learning architecture.
- Data preprocessing and feature engineering.
- Real-time prediction and monitoring capabilities.

## Technologies Used

## Dataset
The model utilizes ADS-B flight trajectory data containing temporal and positional information of various aerial vehicles. The dataset undergoes preprocessing, normalization, and feature extraction to improve model performance.
